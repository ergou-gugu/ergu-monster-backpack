# 王二咕的怪物背包 / Ergu's Monster Backpack

> 一只会长大的怪物背包:能装东西、会长大、能挂挂饰,穿在身上,也能放到地上。

Minecraft **26.2** · Fabric

## 状态

**设计完成(v1.1),尚未开始编码** —— Fabric 26.2 工程与构建骨架已就绪。
完整的玩法与技术方案见 [`DESIGN.md`](DESIGN.md)。

## 构建

```bash
./gradlew build
```

产物在 `build/libs/ergu_monster_backpack-<version>.jar`
(`-sources.jar` 是开发用的,别发布)。

本机实机验证:在工程根目录跑 `gradlew.bat runClient`(Windows)。
